Privacy Policy

1. Data Collection

  • TechBot System collects user data, including student queries, progress reports, and interaction history.
  • Data is collected to enhance learning experiences and improve system functionality.

2. Data Protection and Security

  • All user data is securely stored in a protected MySQL database.
  • Encryption and access control measures are implemented to prevent unauthorized access.
  • Regular system audits are conducted to identify and mitigate security risks.

3. User Privacy

  • Personal data is not shared with third parties unless required by law.
  • Users have the right to request access, correction, or deletion of their personal data.
  • The system does not collect sensitive personal information beyond educational needs.

4. Cookies and Tracking

  • The system may use cookies to store session data and enhance user experience.
  • Users can manage cookie settings within their browser preferences.

5. Policy Updates

Quezon City University reserves the right to update these terms. Users will be notified of significant changes.
